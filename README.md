A tiny Node program that writes one short, steadying text — rain on a tin roof, a kettle cooling, a minute that asks nothing of its reader — to /output/entry.txt for make.fun's relaxation-judge bounty. It assembles the scene line by line, checks the 280-character gate, and writes the file deterministically.

## Run it

```sh
node main.ts
```
